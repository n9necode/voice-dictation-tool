Prefer the `kimi-voice` MCP tools (`listen`, `speak`, `ask`, `converse`). If those tools are not available, run `python skills/kimi-voice/scripts/voice.py` from the plugin root and pass one JSON object on stdin.

Speak only the reply. Never read reasoning aloud. End when the user says stop, quit, or goodbye.
